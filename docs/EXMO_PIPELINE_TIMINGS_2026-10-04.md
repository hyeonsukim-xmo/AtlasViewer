`—`는 해당 경로의 독립 계측 단계가 없다는 뜻이다. LAT의 면적 계산은 Desktop 결과 준비에 포함되고, X-ray에는 3D 단계가 없다. AP의 원본 복원에는 텐서 전송·argmax·보간이 포함된다. LAT 추론은 5-fold·mirroring·blending을 포함한다. MRI 후처리는 PP500이며, 별도 Strong 후보 생성은 포함하지 않는다.

중첩 계측은 부모 시간에서 빼므로 저장에 측정·검증 시간이 중복되지 않는다. Desktop 결과 준비는 내부 처리와 worker 초기화·통신을 합한 값이다. 엔진 초기화·통신 및 잔여시간은 측정된 구간 사이의 차이로 계산했다. 기타 런타임 처리는 개별 타이머 밖의 라이브러리 준비·정리 등이며, 이를 추론으로 표시하지 않는다.

CT는 추론 82.91초와 복원 28.75초, MRI는 저장·복사 28.50초, LAT는 추론 136.25/131.55초가 큰 구간이다. MRI의 해시·재읽기 검증은 0.44초였다. 이전 “저장·검증” 묶음은 이들을 구분하지 못했다.

## LAT 불일치의 실제 의미

같은 입력을 같은 모델로 두 번 실행했을 때 일부 출력 픽셀의 class가 달라진 현상이다. 아래 값은 앞선 반복 검사의 첫 번째와 두 번째 Mask를 다시 비교한 결과다.

| 항목 | LAT 좌 | LAT 우 |
|---|---:|---:|
| 변경된 픽셀 / 전체 | 241 / 22,862,532 | 186 / 22,862,532 |
| 전체 영상 대비 비율 | 0.001054% | 0.000814% |
| 구조별 면적 차이 최댓값 | 0.0010952 cm² | 0.00394272 cm² |
| 원래 class 경계 밖에서 바뀐 픽셀 | 3 | 0 |

경계는 원래 Mask에서 상하좌우 이웃의 class가 다른 두 픽셀을 모두 표시한 기준이다. 따라서 대부분은 경계 픽셀의 변화다. 비율의 분모는 배경을 포함한 전체 영상이며 정확도·임상 허용 기준으로 해석하지 않는다.

전달받은 패키지의 repeatability_details.json에도 LAT 반복 차이가 기록되어 있다. 설치된 nnU-Net이 CUDA benchmark와 autocast를 사용하는 것은 확인했지만, 어느 설정이 이번 차이를 만들었는지 분리 실험으로 확정하지는 않았다. 이번 수정은 계측과 보고 방식이며 모델·정밀도·TTA를 바꾸거나 반복 불일치를 해결한 작업이 아니다. 픽셀 단위 동일성을 요구하는 체커는 이 차이를 실패로 기록한다.
